# Study Time Scheduler

## About the Project
Study Time Scheduler is a simple web application designed to help students organize their study time efficiently.

Students can add subjects, set study durations, track completed subjects, and monitor their study progress.

## Inspiration
Inspired by Study OS, a student productivity product discovered through Product Hunt.

Our project uses this inspiration to create a simple and student-friendly study scheduler.

## Features
- Add subjects
- Set study duration
- Track completed subjects
- View total study time
- Monitor study progress
- Delete subjects
- Manage subjects using React Context

## Technologies Used
- Next.js
- React
- TypeScript
- CSS
- React Context
- Dummy Data

## Getting Started

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Navigate to the project folder:

```bash
cd study-time-scheduler
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
